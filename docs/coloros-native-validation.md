日期：2026-09-23。版本：`1.28.0-coloros.2-test`，versionCode `37`。

已在下述设备接通 OPlus 原生混色、边缘高光和阴影。高光开关对照可见边缘变化，模糊与圆角保持正常。原生描边较细，当前调校偏克制。**这不是完整凝光折射；没有实现背景折射位移或触摸光学反馈。**

本机没有 Gboard，使用已安装的搜狗完成真实切换；仓库推荐流程中的 MIUI 属性与 MIUI 底栏检查不适用于 ColorOS，没有改动这些属性。没有卸载应用、重启设备或系统框架，也未更改权限及 Xposed 作用域。

强制停止微信输入法后，本机 ColorOS 会自动把默认输入法切到搜狗。必须再次核实系统当前选择，不能根据历史输入法日志判断屏幕上显示的是微信输入法。此次未因此修改输入法生命周期 hook。

## 实现证据

原生混色来自当前设备 `OplusBlurParam`；描边和阴影来自 `OplusMaterialUtil` 与 RenderNode 背景效果。使用系统平滑圆角权重，而非固定某个系统控件的参数。接口的布尔返回值表示参数是否改变，不能单独证明可见效果，因此同时检查了运行状态、开关对照截图和隐藏后的清理。

系统独立后处理服务存在签名权限要求；本版仅调用输入法自身绘制节点可用的接口。私有接口变化时保留普通模糊、tint 和模块高光回退。系统包、反编译源码、手机截图和完整诊断日志保存在本地忽略目录，不随 Release 或仓库公开。
